# Defensive security intro


### Theory
- Defensive security is part of cybersecurity, where SOC analyst, cybersecurity engineer etc ensure the security of the organization's infrastructure
- SIEM tool is tool, which get information about organization's infrastructure events, if SIEM detect something suspicious an alert will be generated
